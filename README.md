# Agenda de Contatos - Árvore Binária de Busca (BST)

Projeto desenvolvido em linguagem C utilizando uma Árvore Binária de Busca (Binary Search Tree - BST) para armazenar contatos em ordem alfabética.

## Funcionalidades

- Inserir contatos
- Buscar contatos
- Listar contatos em ordem alfabética
- Remover contatos
- Menu interativo
- Compilação utilizando Makefile

## Estrutura do Projeto

```
AGENDA-DE-CONTATOS-BST
│
├── main.c
├── agenda.c
├── agenda.h
├── Makefile
└── README.md
```

## Compilação

```bash
make
```

## Executar

```bash
make run
```

## Limpar arquivos compilados

```bash
make clean
```
